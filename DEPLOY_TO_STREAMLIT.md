# 🚀 DEPLOY IN 3 CLICKS - Streamlit Cloud

**DO NOT use terminal or command line!**

Just follow these 3 simple steps in your browser:

---

## Step 1: Open Streamlit Cloud
Go to: **https://share.streamlit.io**

(Don't deploy from terminal - use the website!)

---

## Step 2: Sign In with GitHub
1. Click the **Sign in with GitHub** button
2. Log in with your GitHub account
3. Authorize Streamlit to access your repos

---

## Step 3: Deploy Your App
1. After signing in, click **"New app"** button (top right)
2. Fill in these details:
   ```
   Repository: kajoot/the-hollow-library
   Branch: main  
   Main file path: ai/app_simple.py
   ```
3. Click **"Deploy"**
4. **Wait 2-3 minutes** ⏳

---

## ✅ You're Done!

Streamlit Cloud will automatically:
- Pull your code from GitHub
- Install dependencies
- Deploy your app
- Give you a live URL

**Your live app URL will be something like:**
```
https://the-hollow-library.streamlit.app
```

---

## 🎯 What You'll See

After deployment:
1. Login page with Hollow Library theme
2. Register with Hogwarts house selection
3. Message board
4. Toxicity detection (try posting "crap" - it gets blocked!)

---

## ⚠️ Common Issues

**"App's code is not connected to remote repository"**
→ You're using the wrong method. Use **https://share.streamlit.io** in your browser, not terminal!

**"Can't find the repository"**
→ Make sure you signed in with GitHub and it shows `kajoot/the-hollow-library` in your repo list

**Deployment taking too long**
→ First deployment can take 3-5 minutes. Be patient!
